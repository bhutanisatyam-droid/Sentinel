# Directives (Layer 1)

This directory contains Standard Operating Procedures (SOPs) written in Markdown. These are natural language instructions that define:

- Goals
- Inputs
- Tools/Scripts to use
- Outputs
- Edge cases

**Usage:**
Read these files to understand _what_ needs to be done. Then use the tools in `../execution/` to actually do the work.

See `../AGENTS.md` for more details on the 3-Layer Architecture.
